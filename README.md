# RobotTanuki

USI対応将棋思考エンジン

## About

本プロジェクトは、nodchipさんが講師を務める「将棋AIの作り方」講座で作成したものです。
講座では nodchip さんの [RocketTanuki](https://github.com/nodchip/RocketTanuki) を題材に、実装を進めながら将棋AIの作り方を学びました。

（元の実装コードは講座の学習用として本リポジトリに含めていましたが、現在は自分の実装のみを管理しています）
